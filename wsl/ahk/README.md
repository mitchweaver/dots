# AHK

note: make sure you install version 2

```
choco install autohotkey.install
```

## dll for workspace-switcher

grab this DLL from here:

https://github.com/Ciantic/VirtualDesktopAccessor/releases/

and put it in the ahk repo


## notes

```
! = Alt
^ = Ctrl
# = Win
+ = Shift
```

## on startup

`win + r` then type `shell:startup`
right click .ahk files and choose 'create shortcut'
move shortcuts into the opened folder
